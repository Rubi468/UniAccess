# UniAccess

**Sistema de Registro Vehicular — Universidad Tecnológica de Cancún**

UniAccess es una aplicación móvil desarrollada en Flutter que permite a estudiantes y personal administrativo gestionar el acceso vehicular al campus de la Universidad Tecnológica de Cancún. El sistema incluye autenticación, generación de códigos QR y control de perfiles.

## Características

- Inicio de sesión para estudiantes
- Registro de cuenta con validación de datos
- Interfaz institucional con colores y logo de UT Cancún
- Navegación entre perfiles (Estudiante / Administrativo)
- Generación de QR para control de acceso

---

## Tecnologías utilizadas

- **Flutter** — Framework principal
- **Dart** — Lenguaje de programación
- **Firebase** — Para autenticación y base de datos
- **GitHub** — Control de versiones
